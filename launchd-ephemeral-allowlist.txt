# WHY A THIRD CATEGORY (smDrainGate4, 2026-09-05; SM 1218198174895655). The census had exactly
# two escape hatches before this file: FOREIGN (not ours at all — vendor-installed) and DIVERGENCE
# (ours, persistent, vault copy deliberately differs from the live one). Neither shape fits a job
# that is ours, loaded only for the duration of one condition, and re-plants itself with a runtime
# parameter baked into the plist body every time — com.braatz.travel-mode-rearm is planted by
# strike-zone/tools/travel-mode/travel-mode.py's plant_rearm() with `until_dt` written straight
# into the StartCalendarInterval, and removed by clear_rearm() when travel mode ends. There is no
# fixed body to commit: committing today's plist would commit today's departure date. Before this
# file, a census run WHILE travel mode is armed would count it "unbacked" and FAIL G-AE — a false
# positive, because the schedule is not undocumented, it is DERIVED, and the script that derives
# it (travel-mode.py) is itself repo-backed and version-controlled. Measured 2026-09-05: the job is
# not currently loaded (a rebuild loses nothing today), so the failure is dormant, not live — this
# file exists so the next person to run `travel-mode.py enter` mid-gate-run does not get an
# UNBACKED false alarm for a job that was never meant to be backed.
#
# THE BAR FOR AN ENTRY HERE, and it is a high one, same spirit as the divergence file's bar:
#   1. The job's SOURCE OF TRUTH (the script that plants/removes it) must be repo-backed — an
#      ephemeral job with no committed generator would be a real gap, not a false positive.
#   2. A RETIRE-WHEN clause: the condition under which this entry stops being true (the generator
#      is deleted, the label is renamed, the job becomes permanent) — read at every gate wrap the
#      same way the divergence file's entries are.
#   3. A REVIEWED date, so staleness is visible without re-deriving the reasoning.
#
# A job matched here is NOT exempted from being seen — the drill still names it in the output as
# ok(ephemeral); it is exempted from being COUNTED as unbacked and failing the gate.
